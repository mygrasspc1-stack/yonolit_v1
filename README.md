# یونولیت دکور

یک سایت استاتیک RTL با **پنج صفحه‌ی مستقل** برای معرفی خدمات طراحی و ساخت با EPS / یونولیت.  
هر صفحه محتوای مخصوص خودش را دارد و انیمیشن‌هایش با **GSAP + ScrollTrigger** اجرا می‌شود (نسخه‌ی کتابخانه به‌صورت لوکال در `vendor/gsap/` نگه داشته شده است؛ بدون نیاز به CDN).

## صفحه‌ها

| صفحه                | موضوع            | بخش‌های اصلی                                                                       |
| ------------------- | ---------------- | ---------------------------------------------------------------------------------- |
| `index.html`        | خانه             | هیرو، سه مسیر خدمت، نمونه‌کارهای منتخب، فرآیند، کاربردها، گالری، پرسش‌ها، فرم تماس |
| `services.html`     | خدمات و فرآیند   | چهار گروه خدمات، تحویل‌دادنی‌ها (پنل افقی)، تایم‌لاین ۸ مرحله‌ای، پنج متغیر قیمت   |
| `portfolio.html`    | نمونه‌کارها      | سه پروژه‌ی مرحله‌به‌مرحله، آرشیو کامل با فیلتر، لایت‌باکس                          |
| `applications.html` | کاربردها و صنایع | پنج صنعت با تب، داده‌ی بازار، مقایسه‌ی متریال، پرسش‌های متداول                     |
| `contact.html`      | درخواست ساخت     | فرم برآورد با اعتبارسنجی، مسیر اجرای درخواست، نکات ارسال فایل                      |

## اجرا

```powershell
python -m http.server 4173
```

سپس به `http://localhost:4173/` بروید.

## ساختار

- `index.html` … `contact.html`: پنج صفحه‌ی سایت
- `styles.css`: سیستم بصری مشترک + استایل بخش‌های جدید (`v5`)
- `script.js`: رفتار مشترک — منو، گالری، فیلتر، لایت‌باکس، فرم درخواست (`buildProjectMailto`)
- `gsap-site.js`: لایه‌ی انیمیشن — ورود صفحه، reveal با اسکرول، شمارنده، پارالاکس، پنل افقی pin، تایم‌لاین، تب‌ها، دکمه‌ی مغناطیسی، نوار پیشرفت
- `vendor/gsap/`: `gsap.min.js` و `ScrollTrigger.min.js` (۳٫۱۳٫۰، لوکال)
- `assets/`: تمام تصاویر پروژه
- `sitemap.xml` و `robots.txt`: نقشهٔ سایت با تصاویر شاخص و راهنمای خزنده‌ها
- `docs/read-this.txt`: متن و استراتژی SEO ارسالی
- `docs/market-research.md`: گزارش بازار EPS با منابع (Firecrawl)
- `docs/lead-research.md`: بریف مشتریان B2B برای پیام فروش
- `docs/seo-audit.md`: ممیزی SEO پنج صفحه با یافته‌های فنی و مقایسهٔ SERP
- `docs/internal-links.md`: نقشهٔ پیوندهای داخلی و متن لنگر هر لینک
- `docs/brainstorm.md`: ایده‌های نسخهٔ بعدی، رتبه‌بندی‌شده بر پایهٔ ارزش به هزینه
- `agents/`: تقسیم نقش طراحی، پیاده‌سازی و QA

## SEO، اسکیما و تصاویر

- هر صفحه `canonical`، `hreflang="fa-IR"` و `x-default`، `robots`، Open Graph و Twitter Card کامل دارد.
- اسکیمای JSON-LD: `Organization`/`WebSite` در خانه، چهار `Service` در خدمات، `ImageGallery` با `ImageObject` در نمونه‌کارها، `FAQPage` و `ItemList` در کاربردها، `ContactPage` در تماس — همه با `BreadcrumbList` صفحه‌ای.
- هشت تصویر پروژه با نام فایل لاتین و بهینه در **۱۳ جایگاه محتوایی** استفاده شده‌اند (نه فقط گالری). متن جایگزین هر تصویر توضیحی است، نه کلیدواژه‌انبار.
- پیوند‌سازی داخلی: هر صفحه از هر چهار صفحهٔ دیگر لینک می‌گیرد؛ لینک‌های زمینه‌ای با متن لنگر توصیفی و پشتیبانی از نشانی دقیق (`?category=` برای گالری و `#tab` برای تب‌های کاربردها).
- فهرست کامل: [docs/internal-links.md](docs/internal-links.md) و ممیزی: [docs/seo-audit.md](docs/seo-audit.md).

> **نکتهٔ صداقت داده:** در این کپی، ایمیل `hello@yonolit-decor.ir` و شمارهٔ تلفن موجود در صفحهٔ تماس **جای‌نگهدار** هستند و از کسب‌وکار تأیید نشده‌اند؛ همینطور وضعیت فرم (فقط پیش‌نویس محلی/ایمیل) باید با سیاست نهایی کسب‌وکار هم‌راستا شود.

- `tools/contract_test.py`: قرارداد رفتاری پنج صفحه — متادیتا، لینک/لنگر/شبکهٔ داخلی، alt و JSON-LD، واقعیات برند و رفتار سازندهٔ ایمیل فرم (با node)

## بررسی سریع

```powershell
python tools/contract_test.py # قرارداد رفتاری: متادیتا، لینک، برند، ایمیل فرم
python tools/link-map.py      # بازتولید نقشهٔ پیوندهای داخلی
python tools/apply-seo.py     # بازاعمال متادیتا و اسکیمای پنج صفحه + ساخت sitemap
```

`apply-seo.py` پیش از نوشتن، از فایل‌های `head` نسخهٔ پشتیبان در `tools/_backup-head/` می‌گیرد.

## نکته‌ی بک‌اند

فرم درخواست ساخت سمت کلاینت اعتبارسنجی می‌شود و درخواست را از طریق برنامه‌ی ایمیل کاربر می‌فرستد  
(`mailto:` ساخته‌شده در `buildProjectMailto`). هیچ داده‌ای روی سرور ذخیره نمی‌شود.  
برای ثبت و پیگیری درخواست‌ها در یک داشبورد، به یک بک‌اند نیاز است (مثلاً Convex) — این کار انجام نشده و  
به‌عنوان گام بعدی باقی مانده است.
